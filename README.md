# Web Development Practice & Olympiad Projects

A collection of web development projects built while practicing frontend and backend development, exploring web technologies, and preparing for programming competitions.

## 📌 About

This repository documents my learning journey through practical web development projects. It includes frontend layouts, HTML and CSS exercises, and backend experiments with Node.js and Express.

The goal is to strengthen my programming skills by building projects, experimenting with new technologies, and applying concepts through practice.

## 🚀 Getting Started

### Frontend Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/AradKuhzad/forOlympiad.git
   ```

2. Enter the repository:

   ```bash
   cd forOlympiad
   ```

3. Open the relevant project's `index.html` file in your browser.

### Backend Projects

Each backend project has its own dependencies. For example, to run the authentication API:

1. Navigate to its directory:

   ```bash
   cd Project2-APIauth
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   node server.js
   ```

The server listens on port `3000`. Other backend projects may have different setup requirements.
